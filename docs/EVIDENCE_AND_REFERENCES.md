## Current Validation Scope

M0 currently validates deterministic procedure-conformance logic using hand-authored synthetic event sequences. The reported M0 result is limited to functional logic validation and does not represent live-camera accuracy, field-performance accuracy, or superiority over external baselines.

## Scientific References

### 1. Conformance Checking
J. Muñoz-Gama. 2018. *Encyclopedia of Big Data Technologies*.

This reference provides the core process-mining concept of comparing observed event logs against a reference process model to identify deviations.

- DOI: https://doi.org/10.1007/978-3-319-63962-8_89-1
- Consensus: https://consensus.app/papers/conformance-checking-muñoz-gama/e612b8f476ab54f88da1a6579b12933f/?utm_source=chatgpt

### 2. Enriching Business Process Event Logs with Multimodal Evidence
Aleksandar Gavric, Dominik Bork, H. Proper. 2024. pp. 175–191.

This work is relevant to MADQAQ Sentinel because it explores converting multimodal evidence such as video, audio, and sensor data into structured event logs, while considering privacy and real-time use.

- DOI: https://doi.org/10.1007/978-3-031-77908-4_11
- Consensus: https://consensus.app/papers/enriching-business-process-event-logs-with-multimodal-gavric-bork/ba28958a2e7e5e5eb776b342ba08c0bf/?utm_source=chatgpt

### 3. Video Process Mining and Model Matching for Intelligent Development: Conformance Checking
Shuang Chen, Minghao Zou, Rui Cao, Zi-Qi Zhao, Qingtian Zeng. 2023. *Sensors*, 23.

This paper is relevant to the planned physical-perception layer because it studies extraction of process information from video and conformance checking against a predefined process model.

- DOI: https://doi.org/10.3390/s23083812
- Consensus: https://consensus.app/papers/video-process-mining-and-model-matching-for-intelligent-chen-zou/60c33615bcd9541a81301ad5994b9102/?utm_source=chatgpt

### 4. Multi-perspective conformance checking of uncertain process traces: An SMT-based approach
Paolo Felli, Alessandro Gianola, Marco Montali, Andrey Rivkin, S. Winkler. 2023. *Engineering Applications of Artificial Intelligence*, 126, 106895.

This work is relevant to uncertainty handling because it studies conformance checking when event traces contain uncertainty in control-flow, time, and data.

- DOI: https://doi.org/10.1016/j.engappai.2023.106895
- Consensus: https://consensus.app/papers/multiperspective-conformance-checking-of-uncertain-felli-gianola/509a8382d461520e99e924441b2c102a/?utm_source=chatgpt

### 5. Conformance checking of process event streams with constraints on data retention
Rashid Zaman, Marwan Hassani, B. V. van Dongen. 2023. *Information Systems*, 117, 102228.

This reference is relevant to the privacy-by-design direction because it investigates conformance checking under limited event-data retention.

- DOI: https://doi.org/10.1016/j.is.2023.102228
- Consensus: https://consensus.app/papers/conformance-checking-of-process-event-streams-with-zaman-hassani/94278977a28a57508a75f27a86234b77/?utm_source=chatgpt
